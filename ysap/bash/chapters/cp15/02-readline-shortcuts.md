# `readline` shortcuts
## Commands (`emacs`-mode)

| Shortcut | Action |
|---|---|
| `ctrl-n` / `ctrl-p` | Navigate command history **forward/backward** |
| `ctrl-a` | Move cursor to **beginning** of line |
| `ctrl-e` | Move cursor to **end** of line |
| `ctrl-w` | Delete word **behind** cursor |
| `ctrl-u` | Delete everything **left** of cursor |
| `alt-f` / `alt-b` | Jump **forward/backward** by word |
| `alt-t` | Swap the **two words** around the cursor |


## Commands (`vim`-mode)

| Shortcut | Action |
|---|---|
| `esc` | Switch to **normal** mode |
| `i` | Switch to **insert** mode |
| `ctrl-n` / `ctrl-p` | Navigate command history **forward/backward** |
| `j` / `k` | Navigate command history **forward/backward (normal mode)** |
| `0` / `$` | Move cursor to **beginning/end of line (normal mode)** |
| `w` / `b` | Jump **forward/backward** by word (normal mode) |
| `dw` | Delete **word** under cursor (normal mode) |
| `d0` | Delete **everything left** of cursor (normal mode) |
| `d$` | Delete **everything right** of cursor (normal mode) |
| `ctrl-e` | Switch readline to **emacs** mode |
